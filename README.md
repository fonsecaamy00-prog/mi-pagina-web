# Perfil Profesional - Amy Fonseca

Página web responsiva inspirada fielmente en el diseño de referencia.

## 🚀 Cómo abrir la página web

Puedes ver la página web de cualquiera de las siguientes formas:

1. **Doble clic**: Abre el archivo `index.html` directamente en tu navegador preferido (Google Chrome, Edge, Firefox, Brave, etc.).
2. **Con Live Server**: Si utilizas VS Code, haz clic derecho en `index.html` y selecciona **"Open with Live Server"**.
3. **Servidor local rápido**:
   ```bash
   npx serve .
   ```
   o
   ```bash
   python -m http.server 3000
   ```

## 🛠️ Personalización
- **Correo**: Modifica el atributo `href="mailto:tu-correo@example.com"` en el botón de **Enviar correo**.
- **Redes Sociales**: Actualiza los enlaces `href="https://linkedin.com/in/tu-usuario"` y `href="https://github.com/tu-usuario"` en los botones inferiores.
